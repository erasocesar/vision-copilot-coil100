# SOP-SKU-03 Alta de un producto nuevo en el sistema de visión

Documento sintético para la demo.

## Material necesario
Vistas del producto en plataforma giratoria con fondo negro, una cada 10° como recomendación y como máximo cada 15°. Con vistas cada 30° el error de ángulo supera la tolerancia de ±10° del robot y el producto no puede pasar a producción.

## Procedimiento
1. Registrar el candidato con sus vistas y ángulos.
2. Evaluarlo en un entorno aislado: precisión de ángulo dentro de ±10° y que no se confunda con productos existentes.
3. Si cumple, el ingeniero de ML o calidad pide la promoción a producción; la aprueba el gerente de planta.

## Criterios de aceptación
Al menos el 90 % de las vistas dejadas fuera con error de ángulo de 10° o menos, y distancia suficiente a todos los productos del catálogo.
