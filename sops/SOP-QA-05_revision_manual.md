# SOP-QA-05 Revisión manual de casos desviados

Documento sintético para la demo.

## Cola de revisión
Cada pieza que el sistema no resuelve con confianza va a la bandeja de revisión. Calidad o el supervisor confirman el producto y el ángulo real.

## Etiquetado
Registrar el producto y el ángulo confirmados. Las etiquetas pasan al conjunto de reentrenamiento; no se reentrena en producción sin evaluación ni aprobación.
